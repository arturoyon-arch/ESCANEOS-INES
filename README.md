# INE-EXTRACTOR (NotaINE)

Aplicacion para extraer datos de INE escaneados (OCR con PaddleOCR + lectura de MRZ, calculo de RFC, exportacion a PDF).

## Que hay en este repositorio

Codigo fuente y scripts de instalacion: `main.py`, `core/`, `ui/`, `models/`, `config/`, `requirements.txt`, `INSTALAR.bat`, `build.bat`.

## App completa lista para usar

La carpeta compilada `NotaINE/` (~940 MB) y el paquete `NotaINE_distribuir.zip` pesan mas de lo que Git permite, asi que el
paquete completo `INE-EXTRACTOR.rar` esta en la seccion **Releases** de este repositorio.
Descargalo, descomprimelo y ejecuta `NotaINE\NotaINE.exe` (o `INSTALAR.bat` para instalar desde codigo).
